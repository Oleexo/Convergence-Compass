# Convergence Compass

[![Deploy](https://github.com/Oleexo/Convergence-Compass/actions/workflows/pages.yml/badge.svg)](https://github.com/Oleexo/Convergence-Compass/actions/workflows/pages.yml)
[![MIT License](https://img.shields.io/github/license/Oleexo/Convergence-Compass)](LICENSE)

**Interactive guide (French and English) to the 27 classes of the Elden Ring mod *The Convergence*.**

👉 **<https://oleexo.github.io/Convergence-Compass/>**

- **Comparison**: cards or a color-coded table of starting stats, filters by family, starting area and damage type, grouping by playstyle, and a comparison sheet for up to four classes.
- **Class page**: armor, weapons, catalysts, spell runes and class item, with their locations in the world. Item and spell names open the item's own page on this site.
- **Where to look**: filters by area and by acquisition type, search, view by region or as a route (grouped by location).
- **Progress**: checkboxes saved in the browser, with a counter per area.
- **Item database** (`#items`): about 1,700 weapons, shields, catalysts, armor sets (with the effect of each piece), talismans, class jewels, spells (sorceries and incantations by class), ashes of war, spirit ashes and consumables (throwing pots, physick tears), with stats, requirements, scaling, effects and how to obtain them. Search (French and English), filter by type or class, sort by name or weight. Descriptions and effects are translated into French.
- **Item page** (`#item/<type>/<name>`): the full entry (stats, effects, pieces, how to obtain), the classes whose page lists it, previous/next item, and links to the other wikis: the mod wiki, the Fextralife wiki (base game) and the mod's interactive map (the exact marker when the wiki gives one).

Unofficial fan project. Light and dark themes, mobile friendly.

## Stack

React 19, TypeScript, Vite, pnpm. The site is static: no server, no API; only the fonts come from Google Fonts.

## Local development

Requirements: Node.js LTS and pnpm (`npm install -g pnpm`). The expected pnpm version is pinned by `packageManager` in `package.json`.

```sh
pnpm install
pnpm dev
```

| Command | Effect |
| --- | --- |
| `pnpm dev` | Development server with hot reload |
| `pnpm build` | Type-checks (`tsc`), then builds the site into `dist/` |
| `pnpm preview` | Serves the `dist/` build locally |
| `pnpm check:i18n` | Checks that every French data string has an English translation, and that `fr.json` and `en.json` have the same keys |
| `pnpm wiki:fetch` | Downloads the item pages of the mod wiki into `.wiki-cache/` (git-ignored) |
| `pnpm wiki:build` | Parses `.wiki-cache/` and regenerates `src/data/items.json` and `items-index.json` |
| `node scripts/items-i18n.mjs missing` | Lists the lines of `items.json` that `items.fr.json` does not translate yet |

## Structure

| File | Role |
| --- | --- |
| `src/App.tsx` | Hash routing: `#` → comparison, `#glint` → class page, `#items` → item database, `#item/weapon/Moonveil` → item page |
| `src/Home.tsx` | Class comparison (cards, table, comparison sheet) |
| `src/Classe.tsx` | Class page |
| `src/styles.css` | Light/dark theme and styles, scoped under `.home` and `.fiche` |
| `src/data/types.ts` | Data types |
| `src/data/classes.ts` | The 27 classes: stats, level, gear, starting location |
| `src/data/det.ts` | Equipment and locations per class |
| `src/data/zones.ts` | Mapping of locations to regions |
| `src/data/prec.ts` | Per-item details taken from the mod wiki (Glint Sorcerer only for now) |
| `src/data/fiche.ts` | Class page entries, acquisition types, progress |
| `src/Items.tsx` | Item database page (`#items`) |
| `src/ItemDetail.tsx` | Item page (`#item/<type>/<name>`) |
| `src/ItemView.tsx` | Parts shared by the list and the item page: French lookup, stat table, effect text |
| `src/data/items.ts` | Item types and lazy loader (the JSON is its own chunk, only fetched on `#items`) |
| `src/data/items.json` | Generated by `pnpm wiki:build`, do not edit by hand |
| `src/data/items-index.json` | Generated with it: normalized name → type and name of every item. The class pages use it to link to item pages without loading `items.json`; names written differently on the class pages are mapped in `ALIAS` in `items.ts` |
| `src/data/items.fr.json` | French translation of the item texts: each English line of `items.json` → its French line (loaded only in French) |
| `scripts/items-i18n.mjs` | Translation workflow: `extract` writes the lines to translate in numbered chunks, `merge` rebuilds `items.fr.json`, `missing` lists what is left |
| `scripts/wiki-fetch.mjs`, `wiki-parse.mjs`, `wiki-build.mjs` | Wiki scraping pipeline: fetch, wikitext parsing, JSON generation |
| `src/i18n.ts` | react-i18next setup, language selection and persistence (`cv-lang`), `td` helper for data |
| `src/locales/fr.json`, `en.json` | UI strings |
| `src/locales/en-data.json` | English translation of data strings, keyed by the French text |
| `public/classe.html` | Redirects old `classe.html#glint` links to `./#glint` |

Progress is stored in the browser's `localStorage` under the key `cv-done-v1`. Each checkbox is identified by the class, the item name and its location text (see `entries` in `src/data/fiche.ts`): editing those texts in `src/data/det.ts` unchecks the box for visitors who had checked it.

### Translations

The data (`src/data/*.ts`) stays written in French: grouping by area and by acquisition type relies on that text. At render time, `td()` replaces each string with its version from `src/locales/en-data.json` when the language is English. After adding or changing a French string in the data, add its translation to `en-data.json` and run `pnpm check:i18n`.

### Refreshing the item database

The database comes from the [mod wiki](https://wiki.convergencemod.com/) (MediaWiki API). Run `pnpm wiki:fetch` then `pnpm wiki:build` and commit the updated `src/data/items.json` and `items-index.json`. `wiki:fetch` calls `curl` (the wiki rejects Node's HTTP client with a 403) and lists the items from the index pages *Weapons*, *Shields*, *Casting Tools*, *Armor*, *Talisman*, *Ash of War*, *Physick Remnants*, *Throwing Pots*, *Spirit Summons* and *Spells*; `wiki:build` prints how many items lack an effect, description or location.

The wiki text is English. The UI looks every line up in `src/data/items.fr.json` when the language is French, and falls back to the English line when a translation is missing, so a refresh never breaks the page. After a refresh, run `node scripts/items-i18n.mjs missing`; to translate what is new, `extract <dir> --obtain` writes numbered `en-NNN.txt` chunks, you write the matching `fr-NNN.txt` files (`id|French line`, lines left out stay in English) and `merge <dir> --obtain` regenerates `items.fr.json`. Item, spell, skill and place names stay in English, like everywhere else on the site; UI labels and item types are translated (`items.*` in the locale files).

### Adding details for a class

Details (wiki link, map, access conditions, grouping location) live in `src/data/prec.ts`, keyed by class identifier, then by exact item name, or by `runeN` for spell rune tier N (0 = Faint). The comment at the top of the file describes each field, and the `Prec` type in `src/data/types.ts` checks them.

## Deployment

Every push to `main` runs the `.github/workflows/pages.yml` workflow, which builds the site with pnpm and publishes it to GitHub Pages. The site uses relative paths and hash routing, so it works under `/Convergence-Compass/` without any server configuration.

Dependabot (`.github/dependabot.yml`) opens grouped PRs for npm dependency updates weekly and GitHub Actions updates monthly.

## Sources and limitations

- Class pages and rune pages: [convergencemod.com](https://www.convergencemod.com/classes/), accessed October 19, 2026.
- Location details: [mod wiki](https://wiki.convergencemod.com/), accessed October 20, 2026. Text is translated; item and place names stay in English.
- Item database: mod wiki, accessed October 20, 2026. Pages the wiki still marks as incomplete (59 of the 84 shields, among others) show less information, flagged with ⚠. Most ash of war pages only say where to get the ash (their effect is not written on the wiki). Key items and Great Runes are not covered: the wiki has no data pages for them. The common consumables (boluses, raisins, etc.) are not covered either, only throwing pots and physick tears have pages. The French text is my own translation of the wiki, so it may contain mistakes; the English text is one click away with the EN switch.
- Areas and acquisition types are inferred from location text and may contain errors. When two sources disagree, the class page flags it with ⚠.
- None of the sources consulted gives the nearest Site of Grace for each item.
- The mod keeps evolving: a number or location may no longer match the latest version.
